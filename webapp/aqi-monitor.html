About this project

Problem: Estimate Delhi's Air Quality Index (AQI) from weather conditions.

Dataset: Daily weather observations for Delhi, 2013–2016 (731 records), with PM2.5 concentration. No AQI column existed in the source data — AQI is derived here using India's CPCB PM2.5 sub-index formula.

Approach: Supervised regression on 8 weather variables. No pollutant concentrations besides PM2.5 were available, so this is a single-pollutant, weather-only estimation model — not a multi-pollutant AQI model, and not a forecast (the source data has no date column).

Current Python model results: the tuned Random Forest was selected by training-only 5-fold CV R² (0.6826). Its untouched test metrics are MAE 55.7229, MSE 5661.8129, RMSE 75.2450, and R² 0.6474. The browser predictor above is a legacy embedded snapshot, not this current saved model.

Limitations:

  • Weather alone explains roughly half of AQI variance — traffic, construction dust, crop burning and festival fireworks aren't captured.
  • Only 4 years of data from a single city; results won't transfer directly to other locations.
  • AQI here reflects only PM2.5; other pollutants (PM10, NO2, SO2, CO, O3) aren't represented.
  • Educational project, not an official regulatory or medical air-quality source.

Future scope: live weather/pollution API, additional pollutants, true time-series forecasting with dated records, multi-city support.
